# Proyecto final · Introducción a las Ciencias de la Computación (2026-II)

Un agente que busca, se devuelve y deduce, contado en una película 3D con narrador.

## Por dónde empezar

1. **`GUIA_0.md`**: cómo crear el repositorio del equipo en GitHub y conectarlo con este. Se hace una sola vez.
2. **`semana1/guias/`**: la guía de la semana 1, una por mundo. Abran la de su mundo.
3. **`MANUAL_PILOTO.md`**: cómo se construyó el ejemplo de la cueva, paso a paso.

## Qué hay en cada carpeta

- `mundos/`: los mundos, ya construidos. Ustedes no los modifican.
- `Recursos/`: el motor (bitácora, escena, visor 3D). Ustedes no lo modifican.
- `ejemplo_cueva/`: el ejemplo completo (tres generaciones, guion y voces). `python3 correr.py` arma la película.
- `ejemplo_hacienda/`: el mismo agente genérico en otro mundo. Aquí están las generaciones 1 y 2.
- `semana1/`: los programas que usa la guía de la semana 1.
- `CONTRATO.md`: las funciones que ofrece cada mundo.
- `equipo/`: no existe en este repositorio. La crea cada equipo en el suyo, y es la única carpeta que el equipo modifica.

Solo necesitan Python 3.9 o posterior, git y un navegador.
